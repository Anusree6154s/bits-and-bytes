# Express vs Fastify vs NestJS

- Express - slow + unstructured.
- Fastify - fast + unstructured.
- NestJS - slow + structured.
- NestJS + Fastify - moderately slow + structured, using fastify.
  > For large projects w/ nestjs, using fastify along w/ it does no much performance improvement.
