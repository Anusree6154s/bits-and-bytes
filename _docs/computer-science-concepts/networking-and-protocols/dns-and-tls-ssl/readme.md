# DNS and TLS/SSL

- DNS
  - Domain naming system
  - assigns registering a static IP of a website and buying a domain name.
- TLS
  - transport layer security.
  - encrypts data sent b/w client & server.
  - modern version of ssl (secure sockets layer)
  - HTTP + TLS = HTTPS.
